# Java Nesne Yönelimli Programlama (OOP) Uygulamaları

Bu depo, Java programlama dilinde Nesne Yönelimli Programlama (OOP) prensiplerini pekiştirmek amacıyla geliştirilmiş pratik ve ödev çözümlerini içermektedir.

## 📌 İçerik ve İncelenen Konular

- **Sınıf ve Nesne Tasarımı:** `Account`, `Rectangle`, `Stock`, `Fan`, `RegularPolygon` gibi temel modellemeler.
- **Kapsülleme (Encapsulation) & Veri Gizleme:** `Time` ve `MyInteger` sınıfları üzerinde `private` alanlar, getter/setter metotları ve zaman dönüşümleri.
- **Dinamik Bellek & Dizi Yönetimi:** `Course` sınıfı ile dinamik kapasite artırımı (`System.arraycopy`) ve eleman silme/kaydırma işlemleri.
- **Statik Metotlar & Sayısal İşlemler:** `MyInteger` sınıfında asal sayı kontrolü, tek/çift kontrolü ve `parseInt` gibi yardımcı metotların implementasyonu.
- **Matematiksel Modellemeler:** `LinearEquation`, `QuadraticEquation` ve `MyPoint` ile analitik/cebirsel hesaplamalar.

## 🛠️ Kullanılan Teknolojiler
- **Dil:** Java (JDK 21)
- **IDE:** Apache NetBeans IDE
